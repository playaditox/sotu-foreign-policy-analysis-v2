# Historical periods and crisis references

The report retains Cold War, post-Cold War leadership, preponderance under strain and contested U.S. primacy comparisons, together with the displayed boundary and weighting sensitivities. Default message-year groups are 1946–1991, 1992–2001, 2002–2008 and 2009–2026. The under-strain group contains only George W. Bush, so its differences also reflect presidential composition.

The crisis-reference breakdown uses reviewed target wording and adjacent context already shown in the report. It is conservative and nonexhaustive. Remaining foreign-policy text is not established as crisis-free. Removing 2002–2004 is a sensitivity check, not a peacetime counterfactual. Presidency, period and campaign exposure overlap; no adjusted causal era effect is estimated.

Historical events retain their source links in the reviewed `events` query. The event list is an editorial selection, not an exhaustive chronology or evidence that proximity caused rhetorical change.
