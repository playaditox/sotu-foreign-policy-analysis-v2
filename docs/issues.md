# Named international subjects

The public issue view uses transparent, guarded rules within the frozen v2 foreign-policy denominator. It distinguishes broad subject families from specific issue tags and permits overlapping labels. Geography and generic references to the world are context, not automatically specific issues. Domestic policy with only an indirect international connection stays outside the direct-international subject display.

The controls retain the current broad/specific views and earlier issue-rule comparisons shown in the report. All original foreign-policy words remain in the denominator, including text without a named-subject match. Coverage does not establish classification accuracy. The source-linked examples are illustrations, not a representative validation sample.

These issue-rule revisions do not constitute new classifier models. The only fitted classifier distributed in this repository is v2.
